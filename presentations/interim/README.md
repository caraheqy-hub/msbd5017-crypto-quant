# 中期汇报材料

`group27_interim_qiyuan_2min.pptx` 是 Qiyuan 的三页、两分钟部分：问题与目标用户 → 策略和基准比较 → 平台改进与独立验证。配套[讲稿](两分钟讲稿.md)有英文原文、中文提示和交接句，PPT 内也有英文备注。

同学接一页上链内容后，构成四页、三分钟的完整汇报，再由一位组员上传 Canvas。当前版本只覆盖 Qiyuan 的部分。

数字来自 `final_project/cases/three_cases.json` 和 `independent_validation.json`，平台问题来自 `docs/平台改进说明.md`。旧版 PPT 已归档，请勿混用。
