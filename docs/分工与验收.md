## 平台部分怎么分担

先由同学检查已有修改，列出需要补证据的地方，不必重新开发全部功能。需要新增改动时，你可以接数量精度或一组回归测试；同学继续做 next-bar 成交、余额和费用检查等模块，也可以按时间重新分配。

每块任务注明作者和复核人。作者提供代码、提交号、命令与输出，复核人实际检查这些材料。仅浏览代码时，记录为代码审阅；实际运行后才记录为测试复跑。

## 平台复核分两级

A 级是最低要求：在指定 Argo 提交运行关键引擎测试，并检查 168 笔成交及每日净值的对账结果：

```bash
go test ./internal/backtest/engine/engine_v1
```

B 级再构建 WASM 测试文件，运行完整测试：

```bash
make -C e2e/backtest/wasm build
go test ./...
```

这些命令在 Argo 源码仓库执行，本仓库目前没有 Argo 源码。PR 2 需要补上可获取的修复版本、环境要求和对账命令；不能只交本机路径。若提供预构建 WASM 文件，也记录其来源与哈希。A 级通过只说明关键引擎测试通过。
