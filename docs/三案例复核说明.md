## 修正了什么

- 原脚本写死作者电脑路径；现以脚本位置定位仓库内价格、成交、配置，统一命令重建三案例。
- 包中补记指标参数、45% 可用现金下单规则、数量小数位，以及原始账本、源码快照、引擎配置和构建脚本哈希。
- 三案例原来把引擎提交号直接写成既定事实；现标明它来自历史记录，仍需复跑核实。
- 原表把费用列写成正贡献；现明确列为扣减，并补上净贡献。
- 删除“追涨杀跌的代价”等无法仅靠状态表确定的因果解释。现在只描述该状态的持仓与价格损益。
- 新增基准收益、回撤、累计收益差、相对财富增长及分状态平均日超额收益，说明不同指标的含义。

## 尚未证实什么

现已补上独立 Python 指标、信号及成交重放，三案例逐笔日期、币种、方向、数量、价格、费用完全一致，现金及净值误差均小于 2e-11。运行 `python final_project/independent_replay.py` 可重算，结果见 `final_project/cases/independent_validation.json`。

EMA 有一个特定实现细节：不足 60 根时回退 20 根简单均线；达到 60 根后以最近 60 根中的前 20 根简单均值为初值再递推。初版参考程序使用不足 60 根的全部可用历史，得到 392 笔而非 390 笔；检查数据源的“完整窗口不足就返回错误”规则后，按现有引擎的回退规则实现，得到逐笔一致。报告需披露这种初始化方式。

保存的策略和配置快照仍未通过重新编译运行 Argo 来证明与账本的构建来源对应。独立重放验证的是所述算法能产生相同结果，不是策略预测能力。三个案例均不是独立样本外验证，也都尚未上链。
