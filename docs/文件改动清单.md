# 相对 Qiyuan 仓库的文件改动清单

整理日期：2026 年 11 月 20 日。接收人：Qiyuan 及项目组员。

这次工作的核心是：复用 Xinyue 旧工程的存证合约，接入 Qiyuan 的三案例审计包，补充本地和 chainlab 工具、测试、真实凭据及交接证据。Qiyuan已有的量化策略、账本和分析保留原贡献归属；不是重新开发整套量化引擎。

比较基线是本机最初下载的 Qiyuan 仓库提交 `1686b539d79df8f0042acab5c701718076a6a6e9`，不是实时查询 GitHub 最新主分支。此次只在本地整理，没有提交或推送，也没有发送交易。

本清单覆盖当前 Git 可见的 88 个新增或修改文件（含本清单）：新增 49 个，内容修改 20 个，仅换行 19 个。依赖和被忽略的本地生成目录不计入这些数字。

“新增”只表示 Qiyuan 下载基线中没有这个文件，并不表示从零编写：其中包括旧工程迁入、初始化模板和自动生成凭据。以下按实际来源区分。

“仅换行”由程序逐文件对比确认：忽略 Windows CRLF 与 LF 的差异后，内容完全相同。它不是策略算法修改。虽然字节指纹可能变化，但文件含义不变。
